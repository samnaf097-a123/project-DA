# project-DA
Vehicle Sales Dashboard

Project Overview

This project analyzes vehicle sales data using Microsoft Excel and presents key insights through an interactive dashboard.

Tools Used

- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Pivot Charts
- Excel Formulas

Dashboard Analysis

The dashboard focuses on four key areas:

- Category Analysis
- Sales Trend
- Regional Sales
- Order Status

Dashboard

The dashboard provides a clear visual view of vehicle sales performance and helps identify important sales patterns and trends.

Project Files

- Vehicle Sales Dashboard Excel file
- Dashboard Screenshot
- Project Report

Conclusion

This project helped me practice data cleaning, data analysis, and dashboard creation using Microsoft Excel.
